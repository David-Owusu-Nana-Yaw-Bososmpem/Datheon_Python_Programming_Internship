Datheon Python Programming Internship



This repository contains Python projects developed as part of the Datheon Python Programming Internship. The projects focus on programming fundamentals, problem-solving, and practical command-line applications.



Projects



Week 1: Hangman Game



A terminal-based word-guessing game built with Python.



Features

\- Randomly selects a secret word from an English word list.

\- Displays hidden letters as underscores.

\- Allows the player to guess letters one at a time.

\- Tracks previously guessed letters.

\- Prevents repeated guesses from counting as additional mistakes.

\- Limits incorrect guesses to six.

\- Displays win or loss messages and ASCII gallows art.



Technologies

\- Python 3

\- Python standard library (`random`)



Project files

\- `Week 1/hangman.py`: Main game program.

\- `Week 1/google-10000-english-no-swears.txt`: Word list used by the game.



How to Run



1\. Install Python 3 if it is not already installed.

2\. Clone this repository or download it from GitHub.

3\. Open a terminal in the repository's main folder.

4\. Run:



&#x20;  ```powershell

&#x20;  python ".\\Week 1\\hangman.py"

&#x20;  ```



If your system uses the `py` launcher, you can run:



```powershell

py ".\\Week 1\\hangman.py"

```



Keep the word-list text file in the same `Week 1` folder as `hangman.py`.
